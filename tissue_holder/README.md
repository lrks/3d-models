# tissue\_holder

* ティッシュホルダー
* オカムラシルフィーの座面裏ネジ（アームレスト固定用）を使って固定する
  * 左側でも右側でも固定できる
  * アームレストとの併用は不可と思われる
* M8ネジを使って固定する
  * 1本でも固定できるかも知れないが2本が無難
  * 長さは最低10mm程度～最大20mm程度
  * 手元ではこちらのファイルのM8x16mmを使わせてもらった
    * https://makerworld.com/ja/models/398427-fully-printable-knurled-screws-m8
    * インフィルは100%が無難
* 大物なので印刷に注意
  * 45度に傾ければなんとか収まる+ サポート不要で印刷できる設計
  * 接地面積が小さいのでシームやZホップの設定に注意する
  * シームは「最も鋭いコーナー」「スマートシーム」が無難
  * Zホップも設定したいが印刷時間が伸びるので、多少汚くなっても良いなら無視する
